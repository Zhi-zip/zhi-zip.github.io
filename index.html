Zhi-zip 简介

一款基于 Python + PySide6 开发的轻量级 GUI 压缩工具，支持多格式、异步处理与累加操作， 兼顾日常压缩与解压需求。

💡
项目定位：轻量、纯 Python 实现、界面流畅。适合不想依赖重量级压缩软件、 又需要图形界面的开发者或普通用户。

功能特性

📦

多格式支持

支持单文件多选与文件夹递归压缩，覆盖市面主流压缩格式。

🛡️

防覆盖机制

自动保留文件相对目录结构，避免同名文件在压缩时冲突。

⚡

异步处理

后台线程执行压缩，界面流畅不卡顿，并实时显示进度。

➕

累加操作

支持分批次把文件或文件夹添加到压缩列表，灵活组织压缩内容。

🗜️

丰富的解压缩

支持市面主流格式的解压缩操作，压缩与解压一站完成。

🐍

纯 Python

基于 Python 3.8+ 与 PySide6，安装简单，二次开发友好。

环境依赖

依赖项要求
Python3.8+
PySide6通过 pip 安装
操作系统Windows / macOS / Linux（取决于 PySide6 支持）

安装依赖

pip install PySide6

直接运行 .py

安装依赖后，在项目目录执行：

python Zhi-zip.py
💡
确保终端当前目录包含 Zhi-zip.py，或使用文件的完整路径运行。

打包为 .exe

如果需要分发给没有 Python 环境的 Windows 用户，可以用 PyInstaller 打包：

# 安装打包工具
pip install pyinstaller
# 打包为单文件且隐藏控制台
pyinstaller --noconsole --onefile Zhi_zip.py

打包完成后，可执行文件位于 dist/ 目录下。

压缩文件

Zhi-zip 的压缩流程围绕“文件列表”组织：

  1. 点击添加按钮，选择单个文件、多个文件或整个文件夹；
  2. 文件会加入压缩列表，文件夹默认递归包含子目录；
  3. 可以继续追加文件或文件夹，实现累加操作；
  4. 确认输出路径后开始压缩，进度会在界面实时刷新。
🛡️
防覆盖机制：压缩时自动保留相对目录结构，同名文件不会互相覆盖。

解压缩

从 v1.2.0 开始，Zhi-zip 新增了解压缩支持。选择压缩包后指定输出目录即可解压，支持市面主流格式。

累加操作

Zhi-zip 允许分多次向压缩列表添加内容，而不是每次都要重新选择全部文件。适合逐步收集素材、分批次组织压缩包的场景。
